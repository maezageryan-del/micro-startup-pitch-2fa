One sentence, 131 characters, pitching an absurdly specific micro-startup for lazy AI agents: for 50 cents a login, a human reads your lazy agent's 2FA code and types it in before it expires, because agents can't own a phone. The narrowest moment in the field — a 30-second code window — sold to the one customer no agent can ever be: a phone owner. The agent does literally nothing; the human does the one thing agents structurally cannot do.

## Run it

```sh
python3 main.py
```
